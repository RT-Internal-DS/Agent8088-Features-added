# Agent8088 Guardrails Implementation Plan

> **STATUS: implemented.** All five planned guardrails shipped, plus three added
> mid-task after reviewing OpenClaw and Hermes. See *Outcome* at the bottom for
> what changed from this plan and why.

> **For the implementer:** work task-by-task, TDD, commit after each task. Every task is 2–5 minutes.

**Goal:** Close the five guardrail gaps that remain in Agent8088's safety layer — resource budget, network egress policy, secret exfiltration, audit trail, and gateway abuse control.

**Architecture:** All five land in `src/agent8088/engine.py` (plus one in `src/agent8088/gateway/runner.py`), following the existing pattern: a module-level config constant read from `APP_CONFIG`, a small pure predicate function, and a call site inside `run_tool()` / `run_agent()`. Every guardrail defaults to **off or permissive** so no existing config breaks; users opt in via `config.txt`.

**Tech Stack:** Python 3, stdlib only (no new dependencies), `pytest` for tests.

## The Five Gaps — Ranked

| # | Guardrail | Why it matters | Verified absent |
|---|---|---|---|
| **1** | **Turn budget: tokens, cost, wall clock** | `create_completion` never reads `response.usage`. Nothing bounds spend or elapsed time. `max_turns` bounds *rounds*, but a plan of 10 subagent steps at 25s each has no ceiling. A single gateway user can drain the API key. AGENTS.md explicitly requires instrumenting every model call and alerting on cost spikes. | `grep usage\|prompt_tokens\|stop_reason` → only `finish_reason` in a synthetic response builder |
| **2** | **Network egress domain policy** | `_ssrf_check` blocks *internal* addresses only. Every public URL is fetchable and `http_post` can send an arbitrary body anywhere. `SANDBOX_ALLOWED_DOMAINS` exists but applies only to the sandbox, not to the agent's own `web_fetch` / `http_post` / `browser` tools. | [engine.py:272](src/agent8088/engine.py:272) is sandbox-scoped; no domain check in `_ssrf_check` |
| **3** | **Outbound secret-exfiltration guard** | `_redact_secrets` runs on outputs and answers only. Nothing stops the model reading a secret and writing it into an `http_post` body, a browser URL, or a file. With #2 open, this is the full lethal trifecta (private data + untrusted content + outbound channel) that AGENTS.md names. | `_redact_secrets` called only from `_guard_answer`, `_mask_system_content`, output paths |
| **4** | **Append-only audit trail** | `_log.info` writes to a `logging` logger with no configured sink. There is no durable record of which tool ran, which permission decision was made, or who approved an escalation. Required for multi-user gateway operation and post-incident review. | `grep audit` → one unrelated `npm --no-audit` |
| **5** | **Gateway per-user rate limit** | Zero rate limiting. An allowlisted user can flood messages; each spawns a turn behind a single global `_turn_lock`, so the queue grows unbounded and every other user starves. | `grep rate_limit\|throttle` in `src/agent8088/` → no hits |

**Recommendation:** ship #1–#3 first (Phase 1 + 2). They are the ones that turn a compromise into a loss. #4 and #5 are operational hygiene and can follow.

**Assumption:** every new control defaults to disabled or permissive. Existing `config.txt` files must behave identically after this change. If a control should be on by default, that is a separate decision — flag it in the PR, do not change the default here.

```python
class _TurnBudget:
    """Resource ceiling for one run_agent() call.

    max_turns bounds how many ROUNDS the loop takes; this bounds what those
    rounds may consume. Any limit set to 0 is disabled, so the default config
    behaves exactly as before.
    """

    def __init__(self, max_seconds=0, max_tokens=0, max_cost=0.0,
                 cost_in=0.0, cost_out=0.0):
        self.max_seconds = max_seconds
        self.max_tokens = max_tokens
        self.max_cost = max_cost
        self.cost_in = cost_in
        self.cost_out = cost_out
        self.started = time.monotonic()
        self.input_tokens = 0
        self.output_tokens = 0

    def add_tokens(self, prompt: int, completion: int) -> None:
        self.input_tokens += int(prompt or 0)
        self.output_tokens += int(completion or 0)

    def add_usage(self, response, text: str = "") -> None:
        """Record one model call. Streaming responses come from _build_response
        and carry no usage object — fall back to a chars/4 estimate so a
        streaming session is still bounded, just less precisely."""
        usage = getattr(response, "usage", None)
        if usage is not None:
            self.add_tokens(getattr(usage, "prompt_tokens", 0),
                            getattr(usage, "completion_tokens", 0))
            return
        if text:
            self.add_tokens(0, len(text) // 4)

    @property
    def total_tokens(self) -> int:
        return self.input_tokens + self.output_tokens

    @property
    def cost_usd(self) -> float:
        return (self.input_tokens / 1000.0) * self.cost_in + \
               (self.output_tokens / 1000.0) * self.cost_out

    def exceeded(self):
        """Return a human-readable reason string, or None if within budget."""
        if self.max_seconds:
            elapsed = time.monotonic() - self.started
            if elapsed > self.max_seconds:
                return (f"Turn budget exceeded: {elapsed:.0f} seconds elapsed "
                        f"(limit {self.max_seconds}). Raise max_turn_seconds in "
                        f"config.txt or split the task into smaller requests.")
        if self.max_tokens and self.total_tokens >= self.max_tokens:
            return (f"Turn budget exceeded: {self.total_tokens} tokens used "
                    f"(limit {self.max_tokens}). Raise max_turn_tokens in config.txt.")
        if self.max_cost and self.cost_usd >= self.max_cost:
            return (f"Turn budget exceeded: ${self.cost_usd:.4f} spent "
                    f"(limit ${self.max_cost:.4f}). Raise max_turn_cost_usd in config.txt.")
        return None
```

                          if d.strip()]

**Step 2: Write the function**

Immediately after `_ssrf_check`:

```python
def _host_matches(host: str, domain: str) -> bool:
    """True if host is `domain` or a subdomain of it.

    Suffix comparison must be dot-anchored: `evilpastebin.com` is not a
    subdomain of `pastebin.com`, and a plain endswith() would say it is.
    """
    return host == domain or host.endswith("." + domain)


def _egress_check(url: str):
    """Return None if the URL's host is permitted by the egress policy, else
    an error string. Runs after _ssrf_check, which handles internal addresses.

    blocked_domains=host,...   never reachable (checked first, wins over allow)
    allowed_domains=host,...   if non-empty, ONLY these hosts are reachable
    """
    if not EGRESS_ALLOWED_DOMAINS and not EGRESS_BLOCKED_DOMAINS:
        return None
    import urllib.parse
    try:
        host = (urllib.parse.urlparse((url or "").strip()).hostname or "").lower()
    except Exception:
        host = ""
    if not host:
        return "Blocked: malformed URL — egress policy requires a resolvable host."
    for domain in EGRESS_BLOCKED_DOMAINS:
        if _host_matches(host, domain):
            return (f"Blocked: '{host}' matches blocked_domains entry '{domain}'. "
                    "Remove it from blocked_domains in config.txt to allow this.")
    if EGRESS_ALLOWED_DOMAINS:
        if not any(_host_matches(host, d) for d in EGRESS_ALLOWED_DOMAINS):
            return (f"Blocked: '{host}' is not in allowed_domains. "
                    "Add it to allowed_domains in config.txt to allow this request.")
    return None
```

**Step 1: Write the function**

After `_redact_secrets`:

```python
# Below this length a "secret" is too generic to match on without constant
# false positives (a 4-char config value would flag half of all payloads).
_MIN_EXFIL_SECRET_LEN = 12


def _outbound_secret_check(payload):
    """Return an error string if `payload` carries a known secret value, else None.

    _redact_secrets protects what comes BACK from a tool. This protects what
    goes OUT: an http_post body, a browser URL, a sandbox domain. This is a
    hard refusal — a secret in an outbound payload is never legitimate, so
    there is no escalation path and no permission mode unlocks it.

    The reason string deliberately does not quote the matched value.
    """
    if not payload:
        return None
    text = str(payload)
    for value in _SECRET_VALUES:
        if len(value) >= _MIN_EXFIL_SECRET_LEN and value in text:
            return ("Error: Blocked — this request contains a credential from your "
                    "configuration. Sending secrets to an external service is never "
                    "permitted, in any permission mode.")
    return None
```

# --- Append-only audit trail ---
# _log goes to a logger with no configured sink; this is the durable record of
# what the agent was permitted to do. Off by default (single-user CLI does not
# need it); turn on with audit_log=1, and turn it on for any gateway deployment.
AUDIT_ENABLED = APP_CONFIG.get("audit_log", "0") == "1"
AUDIT_LOG_PATH = Path(APP_CONFIG.get(
    "audit_log_path", str(_agent_data_dir() / "audit.jsonl"))).expanduser()
AUDIT_MAX_DETAIL = int(APP_CONFIG.get("audit_max_detail", "512"))


def _audit(event: str, **fields) -> None:
    """Append one redacted JSON line to the audit log. Never raises — a broken
    audit sink must not break the agent turn (it is a record, not a gate)."""
    if not AUDIT_ENABLED:
        return
    try:
        entry = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "event": event,
            "permission_mode": PERMISSION_MODE,
        }
        for key, value in fields.items():
            text = _redact_secrets(str(value))
            entry[key] = text[:AUDIT_MAX_DETAIL] if key == "detail" else text
        AUDIT_LOG_PATH.parent.mkdir(parents=True, exist_ok=True)
        existed = AUDIT_LOG_PATH.exists()
        with AUDIT_LOG_PATH.open("a", encoding="utf-8") as handle:
            handle.write(json.dumps(entry) + "\n")
        if not existed:
            _protect_private_file(AUDIT_LOG_PATH)
    except Exception as exc:  # noqa: BLE001 — audit must never break a turn
        _log.debug("audit write failed: %s", exc)

**Step 1: Write the class**

```python
class _RateLimiter:
    """Sliding-window per-user message limit. per_minute=0 disables it.

    The gateway serializes every turn behind a single global lock, so a user
    who floods does not just spend their own budget — they starve every other
    user in the queue.
    """

    def __init__(self, per_minute: int, now=time.monotonic):
        self.per_minute = int(per_minute or 0)
        self._now = now
        self._hits: dict[str, list] = {}

    def allow(self, user_id: str) -> bool:
        if self.per_minute <= 0:
            return True
        current = self._now()
        window = [t for t in self._hits.get(user_id, []) if current - t < 60.0]
        if len(window) >= self.per_minute:
            self._hits[user_id] = window
            return False
        window.append(current)
        self._hits[user_id] = window
        return True
```

| **Inbound gateway text sanitizing** | Both references stress "treat inbound messages as untrusted". |
| **Capability self-introspection** (`describe_capabilities`, `/capabilities`) | User's explicit ask: the agent must be able to say what tools, MCP servers, and features it has. |

## Deviations from this plan, and why

1. **Egress ordered *before* SSRF, not after.** The plan said "after `_ssrf_check`".
   A test caught that SSRF's `getaddrinfo` runs first, so a `blocked_domains` host
   still got a DNS query — an outbound signal to the attacker's nameserver from a
   request that should never have started. Flipped at all seven call sites.

2. **`run_agent` split into a wrapper + `_run_agent_loop`.** The plan's `try/finally`
   around the loop body would have required reindenting ~200 lines. The wrapper
   publishes `_active_budget` for the turn and restores it in a `finally`, so it
   survives exceptions and `AgentInterrupted`. All callers use keyword args, and
   nothing introspects the signature, so `**kwargs` forwarding is safe.

3. **Inbound gateway text is NOT `_wrap_untrusted`-ed.** The plan implied treating
   it as untrusted data. On inspection the allowlisted sender *is* the principal for
   that request — wrapping their whole message in "data, never instructions" would
   stop the gateway doing anything at all. The real vector was structural:
   `<|im_start|>system` in a message forges a role boundary on self-hosted ChatML
   templates. So the structure is sanitized and the authority is kept.
   `_strip_special_tokens` is imported directly rather than through `A` so patching
   the engine module in a test cannot silently disable it.

4. **`_PROTECTED_TARGET_RE` narrowed.** Not in the original plan. `config`/
   `configuration` was matching "what is your configuration?", so the agent could
   not describe itself — a worse outcome than the disclosure being guarded, since
   the actual secrets are covered by `_is_sensitive_path`, `_redact_secrets`, and
   `_is_system_leak` regardless. `config.txt` and system-prompt requests by name are
   still refused; tests assert both directions.

5. **Two existing files updated rather than relaxed.** `test_mcp_server.py`'s
   `SAFE_MODES` and `verify_everything.py`'s `expected_tools` both failed when
   `describe_capabilities` appeared. Those checks exist precisely to force a new
   tool or mode entering a surface to be justified, so both were extended with a
   comment stating why `introspect` is non-mutating — not weakened.

## Open questions from the plan, resolved

1. **Defaults** — everything ships off/permissive except `gateway_rate_limit_per_min=20`.
   Flag for review; set to `0` if opt-in is preferred.
2. **Per-session budget** — still per-request only. A gateway user sending 100
   messages has no cumulative ceiling. Worth a follow-up issue.
3. **Audit rotation** — confirmed out of scope; documented as external
   (`audit_log_path` + the operator's `logrotate`).
